# Event-level manual validation protocol (not yet performed)

## Why this is required

Step 1 automated source validation compared all 7,165 historical records with 423 independent NBA official L2M JSON reports and matched every game to a PBP source. This does **not** establish that the automated PBP action candidates correspond to the same physical incident. For CNC/INC, no whistle need exist in the PBP at all.

## Data available for review

A reproducible, stratified [48-row queue](../data/validated/step1_review_queue_2025.csv) is generated by `python -m beyond_the_whistle.review_queue --per-grade 12`, using 12 records each of CC, IC, CNC, INC. Rows include official report URL, game ID, period, clock, candidate action and empty human review fields.

This queue is a **pilot**, not a statistically representative, validated precision estimate. A preregistered statistical sample design and appropriate uncertainty intervals must be added before publishing an overall match-precision estimate.

## Review instructions

1. Open the linked official NBA report and locate the exact L2M decision. Confirm period, clock, call type, involved players/teams and NBA ruling.
2. Locate licensed game video of the same period and clock, using the official report's video link where provided. Confirm offense, defense, possession, foul/violation context, and whether a whistle occurred.
3. For CC/IC, compare the source PBP event description, player(s), and possession at the candidate event number. Do **not** infer identity from a clock match alone.
4. For INC/CNC, record an appropriate on-court incident identifier, not an invented whistle event number.
5. Record the video URL/time, reviewer ID, whether the PBP candidate is demonstrably the same incident (`yes`, `no`, `uncertain`, `not_applicable`), reasons, and limitations. The NBA's official retrospective decision is a separate item from the reviewer's own assessment.
6. Assign at least two independent reviewers for a planned confirmation subset. Report agreement (e.g. Cohen's kappa where appropriate) and resolve disputed cases by adjudication. Do not use consensus labels to falsely imply independent original agreement.
7. Store reviewed annotations in a separate file with reviewer provenance and avoid redistributing copyrighted broadcast video.

No blank review field in the queue may be interpreted as `yes`, `correct`, or `no error`. This work has not yet been carried out; no human-verified match precision is claimed.

## Acceptance criteria for later counterfactual impact modeling

- Official L2M decision agrees with official JSON (passed for all 7,165 records).
- Game metadata and source PBP coverage agree (passed for all 423 games).
- The specific event and affected possession must be independently confirmed, or it must be excluded from the incident-level counterfactual subset.
- Noncalls require evidence from the live play/video and explicit corrected-play assumptions, not nearest-whistle imputation.
- The final analysis must report exclusions, reliability, uncertainty and potential selection bias.
